# DotFiles Repository

This repository contains configuration scripts for setting up a Linux environment.

## File and Directories

- **`./bin/lnx.sh`**: Script for setting up the environment. Checks the OS and configures other sh files

- **`./bin/cleanup.sh`**: Script for cleaning up the changes from lnx.sh

- **`MakeFile`**: Automates setup and clean up tasks

- **`etc/nanorc`**: Nano text editor file

- **`.bashrc custom`**: Custom Bash configuration file

## Usage

1. Run make to excute the lnx.sh script
2. Run make clean to undo the changes made by the setup script
